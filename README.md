# AutomateIQ Portfolio

Next.js App Router website for an AI automation agency. It includes the Stitch-inspired home page and the interactive FinOps case study at `/case-study`.

## Local setup

Install Node.js 20 LTS or newer, then run:

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

For a production check:

```bash
npm run build
npm start
```
